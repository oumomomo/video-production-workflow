# 提交前自检

## 分镜提交前

- [ ] 脚本文件哈希一致，未回写原稿；
- [ ] 每个脚本段都被镜头覆盖；
- [ ] 每镜都有视觉事件而非只有抽象名词；
- [ ] 每镜只有一个首要视觉焦点；
- [ ] 已写明与前后镜头的真实衔接；
- [ ] 真实素材、Logo、图标和禁用项明确；
- [ ] 高频六项均有证据并通过；
- [ ] 优化没有改变未授权范围。

## 短样提交前

- [ ] 按正常速度观看；
- [ ] 主体比例、透视、遮挡和裁切合理；
- [ ] 动作没有重复、抢跑或突然停止；
- [ ] 关键内容出现后有可读停留；
- [ ] 没有用无意义装饰掩盖静止；
- [ ] 没有额外卡片替代原画面对象；
- [ ] 清楚说明短样验证什么、不验证什么。

## 连续预览提交前

- [ ] 只使用当前基线或待比较候选；
- [ ] 拒收和被替代片段未混入；
- [ ] 动画与录屏的动作、亮度、比例和声音连续；
- [ ] 无空白帧、重复音频、异常停顿和旧素材；
- [ ] 从头到尾正常速度观看一次；
- [ ] 标注仍未完成或尚未批准的部分。

## 最终候选提交前

- [ ] 脚本、口播、字幕和时间线一致；
- [ ] 前三秒和中后段均保持有效推进；
- [ ] 没有重复总结和无关解释；
- [ ] 品牌、语言、授权和素材来源准确；
- [ ] 输出尺寸、帧率、时长、音轨和清晰度正确；
- [ ] 自动检查结果与人工观看结论分开报告；
- [ ] 文件仍标记为候选，等待用户明确批准。
